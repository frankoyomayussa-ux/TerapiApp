# TerapiApp
TerapiApp es una aplicación web para el acompañamiento y seguimiento terapéutico entre sesiones. Conecta a pacientes y terapeutas para gestionar sesiones, monitorear el estado emocional y asignar tareas terapéuticas. Optimiza la organización y gestión de pacientes para profesionales de la salud mental de forma estructurada y segura.
